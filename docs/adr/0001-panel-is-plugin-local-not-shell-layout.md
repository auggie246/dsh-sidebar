# Panel is plugin-local fixed-position, not a shell layout change

The VS Code-style bottom Panel must live under the center conversation column. The DSH shell grid has exactly one row (`grid-template-rows: 100%` in the built `@deepseek-ai/dsh-client-ui-layout` package), so a true docked bottom row would require patching the installed DSH shell — code this repo does not own, which any DSH upgrade or reinstall would overwrite. We decided the Panel is rendered by the dsh-sidebar plugin itself as a fixed-position element, sized from the shell's layout store values, with injected CSS padding so it never covers conversation content. All of the feature stays inside this repo and survives DSH upgrades. The rejected alternative — extending the built shell package — was the only construction that gives true grid docking, and we gave it up deliberately in exchange for ownership of the whole change.
