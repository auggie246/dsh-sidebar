# The terminal renders the prompt from plugin-owned resources, not machine fonts

The Panel's terminal tabs draw whatever the shell prints, and the user's shell is zsh with Powerlevel10k. Two machine dependencies broke that rendering on a stock GUI machine. First, p10k's default prompt is built from Nerd Font private-use-area glyphs (U+E000–U+F8FF): the os badge U+F179, the folder U+F07C, the git branch U+F113, the commit hash U+F126. This machine has no Nerd Font installed, so every icon rendered as a tofu hexbox. Second, `dsh-subprocess-local`'s `spawnTerminal` hard-codes `name: 'dumb'`, which node-pty turns into `TERM=dumb` inside the shell — an `env` override passed to `spawnTerminal` loses that race (node-pty applies `opt.name` after merging the env), so p10k fell back to plain prompts and once redrew the prompt in a 32-copy storm.

We decided both fixes live in the plugin (ADR 0001), shipped together because they serve one contract: the terminal renders the real prompt with no machine setup. The icons travel as a vendored webfont — the p10k default icon inventory (165 private-use-area codepoints, manifest in `scripts/nerd-icon-glyphs.txt`) subsetted from SymbolsNerdFontMono into a ~33 KB woff2, embedded as a data-URI `@font-face` in the client stylesheet, with `TERM_FONT_FAMILY` leading with the face and falling through to the system mono stack. Rebuild with `npm run build:nerd-icons`. `TERM` is fixed by prepending `env TERM=xterm-256color` to the spawn argv — the one seam that beats the hard-coded name.

Consequence: prompt icons render identically on every machine, including permanent and dynamic installs (the face rides the client twins, so both install paths carry it); ASCII, box drawing, and prompt arrows stay on the system stack because the subset is icon-only. The argv seam is revertible independently: if dsh-subprocess-local later honors a TERM env or grows a `termName` option, the prepend can be dropped without touching the font. Known limit: the manifest covers p10k's defaults, not every Nerd Font codepoint — a prompt configured with exotic icons needs the manifest extended and a rebuild.
